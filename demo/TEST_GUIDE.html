🔧 Cách Fix (Cần DBA):

Chạy SQL sau với quyền GMS_ADMIN hoặc SYSDBA:

GRANT SELECT ON GMS_ADMIN.RELATIVES TO GMS_APP;
GRANT SELECT ON GMS_ADMIN.STUDENT_RELATIVES TO GMS_APP;
COMMIT;
